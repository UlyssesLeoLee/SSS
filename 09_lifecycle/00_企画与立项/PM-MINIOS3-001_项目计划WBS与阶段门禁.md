## 2. 依赖路径
```
SRS评审 → 架构不变量评审 → 接口/模型冻结 → E0 Rust PoC → UT → IT → ST → UAT → 切换演练 → 发布
```
任何P0故障需阻断后续阶段通过。阶段门禁通过必须关联可检索的CI、日志、扫描、评审签字证据（当前均尚未产生）。
